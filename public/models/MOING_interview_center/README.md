# MOING 면접센터 — 3D 공간 전달 파일

웹 시뮬레이션(https://claude.ai/artifact/6LbJx6Xxp39fc6XvSTtEN4)과 같은 버전의 공간 데이터입니다.

## 폴더 구성

| 폴더                                   | 내용                                                                                                                       |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `blender/MOING_interview_center.blend` | 전체 공간 원본 (Blender 4.2+ / 5.x). 모든 방, 창밖 도시, 앉아 있는 NPC(김대리·대기 면접자), NPC·좌석 위치 마커(Empty) 포함 |
| `glb/`                                 | 스테이지별 GLB (원본, 압축 없음)                                                                                           |
| `glb_web_compressed/`                  | 같은 GLB를 meshopt로 압축한 웹용 버전 (`EXT_meshopt_compression`, three.js는 `MeshoptDecoder` 필요)                        |
| `character/char_male_candidate.glb`    | SD 남자 캐릭터 (스킨 + 리그 + 손 흔들기 애니메이션 1개), 얼굴 노멀 수정본                                                  |
| `data/scene_data.json`                 | 좌석·문·스폰·NPC·키오스크 위치 등 게임 로직용 데이터                                                                       |
| `data/walk_grid/*.bin`                 | 이동 가능 영역 그리드 (0.1 m 셀, 1바이트/셀, 1 = 걸을 수 있음)                                                             |

## 스테이지

| GLB                  | 포함 공간                                        | 비고                                |
| -------------------- | ------------------------------------------------ | ----------------------------------- |
| `main.glb`           | 로비 + 면접자 복도 + 면접관 복도 + 파우더룸·카페 | 하나로 이어진 공간 (화면 전환 없음) |
| `cand_wait_01.glb`   | 면접자 대기실 01                                 | 인사팀 테이블(김대리), 라운지       |
| `int_wait_01.glb`    | 면접관 대기실 01                                 | 준비 테이블, 팬트리, 라운지         |
| `interview_01_A.glb` | 면접실 A — 오크 슬랫                             | 10 × 9.5 m                          |
| `interview_02_B.glb` | 면접실 B — 라운드 테이블                         | 10 × 9.5 m                          |
| `interview_03_C.glb` | 면접실 C — 창가 패널                             | 10 × 9.5 m                          |
| `city.glb`           | 창밖 도시                                        | 창문을 통해서만 보이게 쓰는 배경    |

방 스테이지들은 월드 좌표상 서로 떨어진 위치(x 약 70 ~ 200 m)에 배치돼 있고, 문으로 들어갈 때 스테이지를 바꿔 로드하는 구조입니다.

## 좌표·단위

- 단위: 미터. GLB는 glTF 표준(Y-up)이며 Blender에서는 Z-up입니다. 변환은 Blender (x, y, z) → glTF (x, z, −y).
- `scene_data.json`의 좌표는 **Blender 좌표(Z-up)** 기준입니다. `rotz`는 도 단위이며, 0이면 캐릭터가 −Y(glTF에서는 +Z)를 봅니다.
- 캐릭터 GLB 원본 키는 3.6 유닛이므로 **0.5556배로 스케일**해서 쓰면 키 2.0 m가 됩니다. 이 크기에서 엉덩이 높이가 표준 의자 좌면(0.45 m)과 맞습니다.
- 앉은 자세: 의자 좌면 높이 − `char.sit_drop`(0.344 m)이 캐릭터 루트 높이입니다. 허벅지 −88°, 정강이 +80°(캐릭터 좌우축 기준)로 회전합니다.

## scene_data.json 주요 키

- `areas.<이름>`: `origin`, `size`, `grid`(이동 그리드 메타), `seats`(앉을 수 있는 자리: x, y, 좌면 z, rotz, 이름)
- `links`: 복도 문 → 방. `x, y`(문 앞 상호작용 위치), `spawn`(방 안 도착 위치·방향), `back`(복도로 돌아올 위치), `exit`(방 안 나가기 위치), `label`
- `npcs`: NPC 배치 (`pose`: sit/stand, `palette`: 정장 색, 앉은 NPC는 z 포함)
- `resv`: 로비 리셉션 데스크 키오스크 앞 위치 3곳
- `hr`: 김대리 대화 위치(`x, y`)와 김대리 위치(`nx, ny`)
- `start`: 로비 시작 위치

## 이동 그리드 (walk_grid/*.bin)

- 파일당 `nx × ny` 바이트, 행 우선(row-major), j = 0이 남쪽(y0)입니다. 셀 (i, j)의 중심은 (x0 + (i + 0.5)·0.1, y0 + (j + 0.5)·0.1)입니다.
- 가구·벽 그대로의 원본입니다. 웹 시뮬레이션에서는 캐릭터 반경 0.4 m만큼 침식(erosion)해서 썼습니다.

## 참고

- 가구는 현재 **클레이 톤 단순 모델**입니다. 작업 PC의 원본 Blender 프로젝트에 있는 Sketchfab 에셋(CC-BY)으로 바꾸려면 별도 교체 작업이 필요합니다.
- 머티리얼은 GLB에서 단색 PBR로 단순화돼 있습니다. 로비 대리석 결, 창밖 건물 창문 띠는 웹에서 셰이더로 그린 효과라 GLB 자체에는 없습니다.
- 천장은 `rt_ceiling` extras 속성이 붙어 있습니다. 3인칭에서는 숨기고 1인칭(면접 의자)에서만 보이게 썼습니다.
